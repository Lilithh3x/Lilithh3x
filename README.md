# Oi! Sou Eloii / Lilith

</div>

Meu foco é cibersegurança, mas o que me move mesmo é a curiosidade de entender como as coisas funcionam. Gosto de olhar por trás de uma aplicação, investigar suas proteções e ir além do “funcionou”: quero entender o porquê. Aplicações Android, engenharia reversa e instrumentação são temas que aparecem bastante nos meus estudos e projetos.

Também gosto de colocar a mão na massa com Linux e automação. Às vezes a ideia é explorar uma proteção; outras, fazer um dispositivo funcionar melhor ou adaptar uma ferramenta ao que preciso. Python, JavaScript e Go fazem parte desse caminho.

### Um pouco do que compartilho

- **[Ulanzi D200 no Linux](https://github.com/Lilithh3x/ulanzi-d200-linux)** — ferramentas para usar e personalizar o dispositivo no Linux.
- **[Entendendo o RootBeer](https://github.com/Lilithh3x/O-que-e-RootBeer)** — um artigo para entender a detecção de root no Android.
- **[Anti-Frida](https://github.com/Lilithh3x/Anti-Frida)** — estudos sobre como aplicações identificam e tentam impedir a instrumentação.

Gosto de compartilhar o que aprendo, incluindo as tentativas e o caminho até a solução — não só o resultado final.
